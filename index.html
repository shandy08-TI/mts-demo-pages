Hanya di versi Laravel

Halaman ini hanya menampilkan tampilan (frontend) yang mirip dengan website utama. Proses simpan data, verifikasi, dan pengelolaan berkas tetap berjalan di aplikasi Laravel pada server utama.

Tentang MTS Al-Mukhsin

MTS Al-Mukhsin merupakan lembaga pendidikan berbasis keislaman yang berkomitmen membentuk peserta didik berakhlak mulia, berprestasi, dan siap melanjutkan ke jenjang pendidikan berikutnya. Proses pembelajaran mengintegrasikan nilai-nilai agama dengan ilmu pengetahuan modern.

Program & Keunggulan

Program Tahfidz

Pendampingan hafalan Al-Qur’an terstruktur dengan target juz tertentu per jenjang.

Pembinaan Akademik

Penguatan mata pelajaran umum dan agama untuk persiapan ke Madrasah Aliyah / SMA favorit.

Ekstrakurikuler

Beragam kegiatan seperti pramuka, olahraga, dan seni islami untuk mengasah bakat peserta didik.

Alur Singkat PPDB Online

  1. Calon siswa mengisi formulir pendaftaran online melalui website.
  2. Data tersimpan di sistem Laravel dan direkap otomatis di Google Sheets panitia.
  3. Pihak sekolah melakukan verifikasi berkas dan menghubungi calon siswa via WhatsApp.
  4. Pengumuman hasil seleksi disampaikan melalui web dan grup resmi madrasah.

Catatan: proses di atas berjalan di backend Laravel pada server utama, bukan di GitHub Pages ini.

Catatan teknis

Halaman ini dibuat sebagai salinan tampilan dari project Laravel MTS Al-Mukhsin dan di-host di GitHub Pages agar dapat diakses dengan mudah oleh siapa saja, termasuk rekan developer yang hanya membutuhkan link preview tanpa setup PHP terlebih dahulu.
