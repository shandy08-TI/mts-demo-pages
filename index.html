Alur Singkat PPDB Online

  1. Calon siswa mengisi formulir pendaftaran online.
  2. Data tersimpan di sistem (Laravel) dan direkap di Google Sheets.
  3. Pihak sekolah melakukan verifikasi berkas dan konfirmasi via WhatsApp.
  4. Pengumuman hasil seleksi disampaikan melalui web & grup resmi.

Catatan: langkah-langkah ini berjalan di backend Laravel pada server utama, bukan di GitHub Pages.
